# Epimetheus Blue

Personal native security control center for one Arch Linux workstation.
The user wants a vibrant, protective, futuristic redesign without generic AI
templates. This is an operational tool, not a game or marketing dashboard.

Preserve file scanning, configured-folder watching, reversible T2-gated
quarantine, reviewable integrity findings, feed updates, hash-only reputation,
browser protection, optional inbound firewall and approval-gated cleanup.

Never imply Defender-equivalent detection, immunity, verified-clean files or
live network telemetry. Unknown, degraded, observed and confirmed are distinct.
Inspection does not enable protection. System DNS, privileged firewall changes
and cleanup retain explicit approvals. No TLS interception or file uploads.

Keep an executable native app, no Electron/browser dashboard migration.
Render real 3D locally; bound GPU cost and provide reduced-motion/compatibility
paths. Preserve readable controls, keyboard operation and exact danger gates.
