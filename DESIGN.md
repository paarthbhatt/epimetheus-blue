# Blue: precision-engineered armor

Native desktop security workspace. Replace the old visual world; preserve
actions, evidence tiers, approval gates and honest limitations.

## Visual system

Midnight blue #152042, ink #101A35, pearl #EFF3FF; cast cobalt #4166FF with
restrained interference orchid #C9A0FF. Amber #FFA96B means review or reduced
coverage; coral #FF6B7A means danger; mint #66D8B0 names active controls only.
Bundled IBM Plex Sans/Condensed; monospace for technical values only.
Open workspaces, deliberate proportions, readable controls. No card walls,
gradient text, decorative scores, starfields, fake traffic or HUD noise.

## Signature

One sculptural three-layer shield: native egui 0.37 / wgpu 30 / WGSL.
Appearance follows File/DNS/Integrity state. Inspection never enables protection.
Motion responds to interaction/real operations; pauses off-page and unfocused;
reduced-motion and static fallbacks retain all controls.

## Workspaces

Overview: actual status, armor, actions, recent evidence.
Scanner: target runway, aligned result strip, recorded evidence.
Quarantine: held-file ledger and explicit restore review.
Firewall: reported state versus draft; rules, stage/keep/undo.
Network: last observed sockets, never invented live traffic.
Cleanup: read-only analysis, manual selection, exact typed deletion gate.
Integrity: change evidence, not a cleanliness certificate.
Feeds/Settings: practical controls, retained versions, explicit setup plans.
Companion: matching language/palette, keyboard access, read-only bridge.

Fit 900×620 with scrolling, not clipped safety controls. Real screenshots and
tests govern acceptance; GPU performance targets remain unmeasured until tested.

## Revised direction after preview feedback

The flat, oversized, low-poly preview was rejected. Build a premium native
instrument frame: compact grouped navigation, rich but controlled material depth,
machined armor with smooth bevels and clear studio highlights, and a disciplined
operating layout. Do not merely add borders or more neon boxes.

Effects must explain function: selecting a shield layer reveals that control's
actual scope, state and next action; navigation and state changes get brief,
interruptible, non-bouncy transitions. No ornamental spinning or fake telemetry.
Validate a revised Overview and shared frame before extending the new treatment
to every workspace. Use finite verification commands, not idle preview servers.
